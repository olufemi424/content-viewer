## Final record-ready script
Your dashboard changed. Instead of rebuilding the same weekly report, ChatGPT Work’s new Data agent can investigate why. Connect an approved warehouse, like BigQuery or Snowflake, then ask one bounded question: “Why did weekly active users drop?” It uses your existing metric definitions and account permissions, shows evidence, and builds a dashboard you can refine. But OpenAI has not published an external accuracy benchmark, so don’t automate the decision. Have the metric owner verify the filters, source tables, and conclusion before anyone acts. Comment “DATA” and I’ll send the five-step review checklist.
