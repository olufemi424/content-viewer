## Audience + difficulty
- **Audience:** freelance builders who need to turn an approved client brief into a testable app concept before deciding whether it deserves a repository.
- **Difficulty:** intermediate; requires a Cursor plan that includes Cloud Agents and Origin.
- **Input:** one bounded, non-sensitive client brief with acceptance criteria and no production credentials.
- **Output:** a live-previewed prototype that a human can reject, revise, or save as a private Origin repository.

- **Reproducibility gate:** confirm the account includes Cloud Agents and Origin, remove client secrets and personal data, define three acceptance checks, start from scratch, inspect the live preview, and create a private repository only after human approval.

## Final record-ready script
Stop scaffolding repos for ideas clients reject.

In Cursor Cloud Agents, choose Start from scratch and paste one approved, non-sensitive brief with three acceptance checks.

Cursor creates a draft Origin repo in the background while the agent builds.

Open the live preview, test the core flow, and compare it with those checks.

If it misses, revise or reject it.

If it passes, you—not the agent—create a private Origin repo and keep building.

Already using Cloud Agents and Origin? Comment DRAFT for the three-check prototype card.

## Risk check (claims needing cautious phrasing)

- Current documentation says Start from scratch requires a plan that includes Cloud Agents and Origin, excluding Free and Plus; availability and plan names may change.
- A live preview demonstrates behavior, not production readiness. Keep security, accessibility, dependency, performance, and code review outside this quick prototype test.
- Do not paste client secrets, personal data, or production credentials into the brief. Use redacted or synthetic inputs.
- Preserve the human gate: the freelancer decides whether to revise, reject, or create the repository and must explicitly choose its visibility.
