## Final record-ready script

Your AI workstation should not take a weekend to configure. Omarchy 4.0.3 puts OpenClaw and Hermes under one Install AI menu. Pick one harness, finish its guided setup, then use the same install from the desktop or terminal. The real workflow is what happens next: open a disposable project, grant only the files and tools it needs, and run one harmless test task. Check the proposed changes before you approve anything consequential. You get a repeatable agent workspace without hand-wiring the launcher, gateway, and terminal entry point. Comment SETUP, and I’ll send the permission checklist.
