## Hook
Y Combinator just open-sourced `QM`, the multi-agent harness it says it uses internally, and that matters because the real story is not another chatbot. It is a company-shaped operating system for agents.

## Why this matters
This matters because most people still use agents like solo assistants in a chat window. `QM` pushes a different model. According to YC's launch post and the repository README, each person and each room gets its own scoped memory, files, permissions, crons, web apps, and durable sandbox. For creators, solo builders, and operators, that is the useful shift: agents stop being one-off prompt sessions and start looking more like reusable team workflows. If you run content, research, support, or internal ops, the bigger signal is that YC is packaging multi-agent work as infrastructure, not as a demo.

## Mechanism
The mechanism is shared context plus isolated scopes. The README says `QM` runs in Slack and on the web, gives personal and shared scopes, supports admin controls, and lets teams run background work through crons and watches. It also says each scope can search internal notes, documents, databases, and the web together, and can work inside existing repositories to run tests, open PRs, and monitor CI. In plain English: instead of forcing one agent to juggle every task for every person, `QM` gives each user or room its own agent workspace and then adds collaboration on top.

## Proof/use case
The proof is that YC did not stop at a teaser thread. The `yc-software/qm` repository is public under the MIT License, lists Slack plus web support, and links a live homepage at `qm.ycombinator.com`. GitHub also shows strong early traction, with 8,772 stars at the time of this run. A clean use case for Olufemi's audience is a small team that wants one agent in a shared content or product channel, plus separate personal agents for drafting, research, CI follow-ups, or reporting. That is a better mental model than "one super-agent does everything," because it mirrors how real teams already work.
