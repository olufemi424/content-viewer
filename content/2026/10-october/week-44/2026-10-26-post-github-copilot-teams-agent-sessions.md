## Final record-ready script
Your Teams thread can now become a coding-agent control room.

GitHub Copilot's Teams integration is in public preview. Mention GitHub in a conversation, and the cloud agent can use that thread to investigate, plan, write code, and open a pull request.

This matters because the brief, clarifications, and progress stay visible where the team already made the decision. Anyone in the conversation can add context, but only people with repository write access can trigger code changes.

Try it with one bounded task from stand-up, like fixing a documented bug. Let the agent work asynchronously in its cloud sandbox, then review the pull request instead of treating chat approval as permission to ship.

Before rollout, check three controls: the thread may become agent context, Teams-started sessions consume AI credits, and cloud sandbox usage is billed separately. GitHub also supports an additional approval for Copilot-authored pull requests.

Save this as your checklist before moving coding agents into team chat.

## Risk check (claims needing cautious phrasing)
- The integration and cloud sandboxes are in public preview and may change.
- The full Teams thread can become context and be stored in generated artifacts; sensitive discussions require deliberate scoping or a direct message.
- Only users with repository write access can trigger changes; guest workspace members and outside collaborators cannot start or steer Teams sessions.
- Teams-started cloud-agent sessions consume AI credits, while cloud sandbox usage is billed separately; exact costs depend on plan and usage.
- The additional approval applies to unattributed Copilot pull requests under GitHub's ruleset conditions and should not be described as universal.
