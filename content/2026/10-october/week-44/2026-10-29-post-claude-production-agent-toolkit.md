## Final record-ready script
Claude agents can now carry a workflow across four layers.

Anthropic moved computer use, Agent Skills, and the Files API out of beta, and launched a browser use tool. That matters because a useful agent needs more than permission to click around.

Here is the mechanism. Files hold the documents an agent reads and creates. Skills package your approved instructions, scripts, and templates. Browser use reads page structure as well as screenshots, so it can target fields and buttons. Computer use can take several actions in one turn.

Picture a client-intake workflow: load the approved brief, follow your onboarding checklist, enter the details into a web portal, then save the confirmation for review. Anthropic uses a similar claims-processing example in its announcement.

Start with one low-risk process. Limit the sites and files it can reach, log the result, and require human approval before any submission or external change.

Save this four-layer pattern for your first production agent.

## Risk check (claims needing cautious phrasing)
- Computer use, Agent Skills, and the Files API became generally available on the Claude Platform on August 19, 2026; browser use launched that day rather than moving out of beta.
- Browser use reads page structure and screenshots, but this does not guarantee correct targeting or task completion in every website.
- Computer use supports several actions per turn; do not claim that this removes latency, errors, or the need for review.
- Anthropic's claims-processing scenario is an illustrative vendor example, not independent evidence of production accuracy or business outcomes.
- Existing beta integrations continue to work while teams migrate, but request shapes and tool handling can differ for upgraded computer-use integrations.
- Require human approval before submissions, purchases, messages, destructive changes, or updates to external systems.
