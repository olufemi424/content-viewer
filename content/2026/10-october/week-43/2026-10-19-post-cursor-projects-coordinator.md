## Final record-ready script
Stop managing every coding agent one task at a time.

Cursor Projects adds a coordinator for work that lasts longer than one chat, like a feature, migration, or recurring maintenance job. You describe the outcome, and the coordinator plans the work, delegates implementation and testing to other agents, then brings the result back for review.

The useful part is continuity. Each Project keeps shared files with research, artifacts, codebase lessons, and your working preferences. That context can sync across cloud and local agents instead of being rebuilt for every task.

It can also watch a Slack channel, run on a schedule, or follow pull requests and CI events. For example, a bug report can trigger delegated investigation while the coordinator keeps the broader project context.

Cursor says Projects is in beta, so treat its productivity numbers as vendor-reported. Start with one bounded maintenance workflow, review every pull request, and only expand once the results are reliable.

Save this before you test a coordinator-style agent workflow.

## Risk check (claims needing cautious phrasing)
