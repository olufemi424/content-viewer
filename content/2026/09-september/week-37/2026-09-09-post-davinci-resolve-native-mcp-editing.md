## Hook
Your video editor just became an AI tool.

## Why this matters
Blackmagic Design released DaVinci Resolve 21.1 with a native MCP server for supported AI assistants. This moves automation from unofficial glue code into an official Resolve workflow, so creators can delegate repetitive project operations while keeping creative judgment in the edit.

## Mechanism
In Resolve Studio, **File > Setup AI Assistants** connects supported clients including Claude, Claude Code, and ChatGPT Codex. The assistant translates plain-language requests into actions through Resolve's scripting interface. Blackmagic's demo shows project analysis, media organization, settings changes, timeline work, and batch rendering. MCP is the bridge; the external assistant is still the reasoning layer.

## Proof/use case
Give the assistant a duplicate project and one long interview. Ask it to build a short highlights timeline, remove obvious dead space, and queue a review render. Then inspect every cut before delivery. That is the useful boundary today: accelerate the first pass, but keep a human on story, pacing, permissions, and final export.
